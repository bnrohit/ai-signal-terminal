## Important scope note

The registration document is evidence about the registered design and its appearance. This repository is an independently documented software demonstrator implementing generic signal-processing, visualization and explainable anomaly-analysis functions. The repository does not state that those functions are legally protected by the registered design, nor does it provide legal advice about patent, design, copyright or other IP rights.
